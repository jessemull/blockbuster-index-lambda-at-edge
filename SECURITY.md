# Security Policy

## Supported versions

The `main` branch and the currently deployed Lambda@Edge versions for **dev** and **prod** are supported for security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for sensitive reports.

Email the maintainer via GitHub (see profile for `@jessemull`) or use [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) if enabled on this repository.

Include:

- Affected environment (dev/prod)
- Description and impact
- Reproduction steps if safe to share

## Baseline controls

See [`docs/SECURITY.md`](docs/SECURITY.md) for secrets, IAM, and S3 expectations.
